# Tatemae-Converter-3000 (Polite-Aggressive Web)

> **「本音を放てば社会が死ぬ。建前を抱えれば精神が死ぬ。ならばAIに語らせよ。」**

現代を戦う全ビジネスパーソンに捧ぐ、全自動・角を立てずに本音をねじ込むWebアプリケーション。
ド直球の怒り・サボり・絶望を、知性と誠実さ溢れる「何も言っていないビジネスマナー構文」へと瞬時に不可逆変換します。

---

## 🌟 主要機能

### 1. タテマエ・トランスレート機能（本音サニタイズAPI）
- ユーザーの荒れ狂う感情（Raw Data）を0.8秒で極上のビジネス構文に変換。
- 入力データは即座にメモリ上でシュレッダー廃棄され、ログに残りません。

### 2. 身代わり召喚ボタン（緊急脱出ダイヤル）
- ポチッと押すと30秒後に謎の非通知着信が発生。
- 「トラブル発生です！」と叫んで地獄の会議から堂々と中途退出可能。

### 3. 言い訳家系図マネジメントDB
- 「今年おばあちゃんは何回忌引になったか？」を厳密に管理。
- 同一親族の多重召還バグを未然に防止する整合性バリデーション完備。

### 4. 緊急ステルスモード（Boss-Key）
- `Esc` 2回押し、またはワンクリックで0.01秒発動。
- 超絶複雑なExcelピボットテーブルまたは流れるソースコード画面へ瞬時に偽装。

---

## 🛠️ 技術スタック

- **Frontend**: Next.js (爆速で言い訳を描画)
- **Backend**: FastAPI / Python (冷徹な論理で感情を隠蔽)
- **AI Engine**: OpenAI GPT-4o (人間関係の修羅場を一番よく知るモデル)
- **Deploy**: Vercel & AWS ("サーバーが落ちてまして…" と言える信頼性)
